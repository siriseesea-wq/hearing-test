# 个人听力测试（hearing-test）

一个**自包含、离线可用**的个人听力测试网页：频段听阈 × 码率盲测，双击 HTML 即可打开，
运行时零网络请求，结果只存在你自己浏览器里，可导出 JSON。

> ⚠️ **版权说明（请先读）**
> 本工具的原始素材是蔡琴《渡口》与 Eagles《Hotel California》的**商业版权录音**。
> 因此**本仓库不包含任何音乐音频**。仓库里只有构建脚本与页面模板；
> `products/hearing-test.html` 作为 [Release 附件](../../releases) 提供的是**构建产物**，
> 其内嵌音频的使用责任由使用者自行承担（个人听力自测属合理使用范畴，**请勿再分发**）。
> 你要用自己的曲目重建，见下文「用自己的素材构建」。

## 它测什么

| 模块 | 做法 | 说明 |
|---|---|---|
| 0 · 校准与音量 | 1 kHz 校准音定音量，全程锁死 | 后续测试以同一数字电平发出 |
| 1 · 频段听阈 | 250 Hz – 12.5 kHz 共 7 个频点，每点 6 档由轻到响的 1.2 s 短音，听到即点 | 得到各频段的**相对听阈曲线**（dB re 0 dBFS） |
| 2 · 码率盲测 | 同曲 128 kbps / 320 kbps / 无损三段随机排列，判断哪段最好、哪段最差 | 得到你在该设备上的**主观区分能力** |
| 3 · 结果与导出 | 听阈曲线 + 盲测正确率 + 元信息，导出 JSON / 打印 PDF | 便于自己前后对比 |

**它不证明什么**：这不是医用听力计——耳机频响未校准、声压级未知，听阈值是相对值，
不能与临床听力图比较；盲测测的是「你 + 这套设备」听不听得出，不是码率在科学上的优劣。

## 快速使用

直接下载 [Release 里的 `hearing-test.html`](../../releases/latest)，双击用浏览器打开。
建议戴耳机；先到「0 · 校准与音量」定好音量，测试中不要改系统音量。

## 用自己的素材构建

需要 `ffmpeg` / `ffprobe`（构建期用，运行时不需要）与 Python 3.9+。

```bash
# 1. 把你的六段素材裁成 30 秒片段，放进 lab/audio/，命名如下：
#    du128.mp3 / du320.mp3 / duflac.flac   （同一首曲目的三档编码）
#    h128.mp3  / h320.mp3  / hflac.flac    （另一首曲目的三档编码）
#    裁剪示例（渡口取前 30 s，加州旅馆取 12–42 s 带人声段）：
ffmpeg -i 你的无损.flac -t 30 -c:a flac -sample_fmt s16 -ar 44100 -ac 2 duflac.flac
ffmpeg -i 你的高码率.mp3 -t 30 -c:a libmp3lame -b:a 320k -ar 44100 -ac 2 du320.mp3
ffmpeg -i 你的低码率.mp3 -t 30 -c:a libmp3lame -b:a 128k -ar 44100 -ac 2 du128.mp3

# 2. 生成自包含页面
python lab/scripts/build_hearing_test.py
# → products/hearing-test.html
```

生成的 HTML 把六段音频以 base64 内嵌，运行时零网络请求；页脚自带素材 SHA-256 指纹，
导出的结果 JSON 里也带同一份指纹，可精确对上「你测的是哪一版素材」。

## 目录结构

```
hearing-test/
├── lab/
│   ├── audio/          # 30 秒裁剪片段（本仓库不含；构建时自备）
│   ├── scripts/
│   │   └── build_hearing_test.py   # 构建脚本：裁剪探针 + base64 内嵌 + 来历注入
│   └── templates/
│       └── hearing_test.tpl.html   # 页面模板（含全部 CSS/JS，无外部依赖）
└── products/
    └── hearing-test.html           # 构建产物（Release 附件，不入库）
```

## 设计要点

- **单文件、离线**：所有 CSS/JS/音频内联，无 CDN、无字体外链，没网也能打开。
- **双主题三态**：浅色 / 深色 / 跟随系统，全部走 CSS 变量令牌。
- **无框架**：原生 Web Audio API + SVG/Canvas，构建期算数据、浏览器端只渲染。
- **反馈可回传**：导出的 JSON 带素材指纹与设备备注，发回即可精确复现你测的那一版。
- **隐私**：结果只写 `localStorage`，不上传任何地方。

## 反馈

发现阈值曲线画得不对、盲测计分有误、或某个浏览器打不开，欢迎开 Issue；
附上「导出 JSON」能得到最快的定位。
